# Atajos de teclado

En Mac, ⌘; en los demás, Ctrl.

## Elementos {#elements}

| Teclas | Qué hacen |
| --- | --- |
| ⌘Z · ⇧⌘Z o ⌘Y | Deshacer · rehacer |
| Suprimir o Retroceso | Eliminar lo elegido |
| ⌘D | Duplicar |
| ⌘C · ⌘X · ⌘V | Copiar, cortar, pegar. Pegar una imagen o texto simple de fuera lo añade a la diapositiva. |
| ⌘A | Elegir todos los elementos no bloqueados |
| Flechas · ⇧ Flechas | Mover 1 punto · 10 puntos |
| Intro | Escribir en el texto elegido |
| Esc | No elegir nada |
| Re Pág · Av Pág | La diapositiva anterior o siguiente, sin nada elegido |
| ⌘S | Guardar el archivo `.reboslides` |

## Al arrastrar {#while-dragging}

| Teclas | Qué hacen |
| --- | --- |
| Alt | Mover sin ajustarse a las guías |
| ⇧ en una esquina de una forma | Conservar sus proporciones |
| ⇧ en una esquina de un grupo | Estirarlo en vez de escalarlo |
| ⇧ al girar | Girar de 15 en 15° |
| ⌘ + rueda | Zoom |

## Al escribir {#typing}

| Teclas | Qué hacen |
| --- | --- |
| ⌘B · ⌘I · ⌘U | Negrita, cursiva, subrayado |
| ⌘A | Seleccionar todo el texto de la caja |
| Alt + Flechas | Una palabra a la vez |
| ⌘ + ← → · Inicio · Fin | Inicio o fin de la línea |
| ↑ ↓ | La línea de arriba o de abajo |
| Esc | Dejar de escribir; la caja sigue elegida |

## Al presentar {#presenting}

| Teclas | Qué hacen |
| --- | --- |
| → ↓ Espacio Intro Av Pág | Diapositiva siguiente |
| ← ↑ Re Pág Retroceso | Diapositiva anterior |
| Inicio · Fin | Primera · última |
| Esc | Volver al estudio |
