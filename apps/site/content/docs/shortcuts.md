# Keyboard shortcuts

On a Mac, ⌘; elsewhere, Ctrl.

## Elements

| Keys | What they do |
| --- | --- |
| ⌘Z · ⇧⌘Z or ⌘Y | Undo · redo |
| Delete or Backspace | Delete what is picked |
| ⌘D | Duplicate |
| ⌘C · ⌘X · ⌘V | Copy, cut, paste. Pasting a picture or plain text from elsewhere adds it to the slide. |
| ⌘A | Pick every element that is not locked |
| Arrows · ⇧ Arrows | Move 1 point · 10 points |
| Enter | Type in the text picked |
| Esc | Pick nothing |
| Page Up · Page Down | The slide before or after, with nothing picked |
| ⌘S | Save the `.reboslides` file |

## While dragging

| Keys | What they do |
| --- | --- |
| Alt | Move without snapping to guides |
| ⇧ on a corner of a shape | Keep its proportions |
| ⇧ on a corner of a group | Stretch it instead of scaling it |
| ⇧ while turning | Turn by 15° |
| ⌘ + wheel | Zoom |

## Typing

| Keys | What they do |
| --- | --- |
| ⌘B · ⌘I · ⌘U | Bold, italic, underline |
| ⌘A | Select all the text of the box |
| Alt + Arrows | A word at a time |
| ⌘ + ← → · Home · End | Start or end of the line |
| ↑ ↓ | The line above or below |
| Esc | Stop typing; the box stays picked |

## Presenting

| Keys | What they do |
| --- | --- |
| → ↓ Space Enter Page Down | Next slide |
| ← ↑ Page Up Backspace | Slide before |
| Home · End | First · last |
| Esc | Back to the studio |
