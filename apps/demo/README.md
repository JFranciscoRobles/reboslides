# Demo

`@reboslides/react` as an application uses it. The same deck two ways, in two tabs:

- **SlideStudio**: the whole studio as it comes, in a line (`src/App.tsx`).
- **Your own interface**: a dark one, laid out another way, built from nothing on the headless hooks: `SlidesProvider`, `useSlides`, `SlidesSurface` and `SlideThumbnail` (`src/Headless.tsx`).

```bash
npm run demo      # from the root: http://localhost:5191
```
