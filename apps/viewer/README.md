# Viewer

`@reboslides/viewer` as an application uses it: decks only to look at.

- **A shelf**: the decks, a deck of each theme and those you open, each with its first slide as a thumbnail, made in the page with `slidePicture` (`src/App.tsx`).
- **A viewer**: one of them opened in `SlidesViewer`, its slides one under another or all at once, presented full screen or printed, a slide to a page.

```bash
npm run viewer        # from the root: http://localhost:5194
```
